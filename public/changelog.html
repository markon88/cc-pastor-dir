Carolina Conference Pastor Directory

June 2026 — Duplicate Phone Number Fix

App version 10.1.3  ·  June 23, 2026
App Improvements
  • Fix
    No more duplicate phone numbers
    Some pastors had the same number listed twice on their detail page — eAdventist sometimes records a "family phone" fallback that matches the cell number, occasionally formatted differently (e.g. with or without dashes). The directory now recognizes these as the same number and shows it only once.

June 2026 — Data Sync Reliability

App version 10.1.1  ·  June 23, 2026
App Improvements
  • Fix
    "Check for Updates" now checks directory data too
    Previously this button only checked for app code updates — it now also pulls the latest pastor and church directory data. The app also refreshes data automatically whenever you reopen it.
  • Fix
    More reliable eAdventist sync
    Fixed a bug where the automatic pastor sync had silently stopped pulling updates — pastor contact info, churches, and assignments now sync reliably every cycle.
  • Fix
    Churches now matched by Org Code
    Congregations are matched by their official conference Org Code instead of name, so renames or reclassifications (e.g. a group becoming a company) no longer create duplicate or stale entries

June 2026 — AMA Schedule in Group View

App version 10.1.0  ·  June 12, 2026
App Improvements
  • Feature
    AMA group schedule tab
    Tap any AMA group to see its upcoming meetings in a new Schedule tab alongside the member list
  • Feature
    Add all meetings to calendar
    One tap adds every upcoming meeting for a group to your calendar as a single download
  • Fix
    App updates now more reliable
    Fixed an issue where "Check for Updates" could get stuck — the app now recovers automatically and reloads
